# AGJ2025

## The theme for this game jam is onomatopoeia.

> Are you a current or aspiring game developer in Alberta? Are you looking for a way to connect with other developers in our community, learn new skills, or experiment with cool ideas? Join us on September 26th - 28th in Edmonton, Calgary, Lethbridge, and Remote for the seventh annual Alberta Game Jam!
> 
> Alberta Game Jam is Alberta's largest game jam event, seeking to unite and empower developers throughout our province. Whether you're a seasoned developer already working in the industry or a novice looking to get started, game jams are an excellent way to get connected to your peers, flex your creative muscles, and gain experience! If you're new to game development, game jams are also a great way to learn the ins-and-outs of the process and start building up pieces for your portfolio.
> 
> [link to the website](https://itch.io/jam/alberta-game-jam-2025)

Our game is coded within the Unity3D game engine, version 6.2.
